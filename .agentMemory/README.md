# Enterprise Auth & Logistics Codebase Memory Bank

Persistent, structured memory bank for the Enterprise Auth System (Flutter Mobile + ASP.NET Core API + Sage X3 ERP).

## Memory Hierarchy:
- **`architecture/`**: High-level systems, data flows, database schemas, and integration points.
- **`patterns/`**: Proven code patterns, precision handling, and concurrency rules.
- **`decisions/`**: Architecture Decision Records (ADRs) explaining technical trade-offs.
- **`active_context/`**: Current active features, tested physical devices, and next steps.
