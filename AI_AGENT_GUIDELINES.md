# AI Agent Development Guidelines

**MANDATORY:** Always use `@concise-planning`, `@recursive-context-pruning-token-budgeting`, and `@llm-prompt-optimizer` for any prompt to minimize token usage and keep responses direct.

## 1. Frontend: Flutter (Dart)
- **@flutter-expert**: Primary agent for multi-platform interfaces. Focus on Dart best practices, state management, and mobile-first design.
- **@mobile-developer**: Use for broader mobile workflows, device constraints, cross-platform performance profiling, and offline-first strategies.

## 2. Backend: .NET (C#)
- **@csharp-pro**: Write modern C# code (records, pattern matching, async/await). Optimize .NET applications and implement robust enterprise patterns.
- **@super-code/csharp**: Enforce strict language-specific guidelines, clean code rules, and uniform formatting in the C# codebase.
- **@backend-dev-guidelines**: Structure overall backend architecture, handle middleware, and define API boundaries.

## 3. Sage X3 Integration
- **@api-patterns**: Bridge the .NET backend with the ERP. Design architecture for XML SOAP payloads (e.g., ZSIHWEBA import template). Troubleshoot sync rejections and manage WebSockets for real-time mobile updates.

## 4. Databases: SQLite & MSSQL
- **@database-design**: Plan schema design and ORM (Entity Framework). Architect local SQLite storage and define synchronization with the central MSSQL datastore.
- **@database-optimizer**: Performance tuning, indexing strategies, and query plan analysis for fast data sync across both systems.
- **@sqlmap-database-pentesting**: Audit database layers and harden MSSQL endpoints against injection vulnerabilities.

## 5. Fully Automated Testing Agents
- **@agent-squad/tester**: Autonomous QA agent. Generate test suites, execute locally, and patch logic iteratively. Validate complex algorithmic rules.
- **@unit-test-loop**: Specialized unit testing loop. Mock dependencies and iterate on failing tests until 100% pass rate (Flutter state management or backend math models).
- **@integration-auto-fix**: Handle cross-service integration testing. Use mock payloads to validate schema and automatically repair .NET integration layers when endpoints reject data.
